For a long time, I've loved tinkering with hardware. However, the closest I have ever been before to actually manipulating hardware was through embedded C++ on microcontrollers like the Arduino UNO and ESP32. 
I decided to learn Verilog to actually describe the structure and behavior of a hardware chip. 
This LED blinker is the first project I've taken on while learning Verilog. It has helped a lot in refining my knowledge of sequential and combinational logic, and signal multiplexing.
